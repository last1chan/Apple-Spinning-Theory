## ✨ Features

- 🍎 Spawn **any number** of apples. No cap, no limits, no mercy.
- 🔄 Every apple spins **in place** on its own random 3D axis.
- 🎨 Random red, green and yellow apples for maximum IQ diversity.
- 📐 Apples **never overlap**. Each one gets its own cell.
- 🔍 The camera **auto zooms out** so every single apple stays visible.
- 📱 Works on mobile. Opening the keyboard won't glitch it.
- ⚡ Uses GPU instancing, so thousands of apples stay smooth on decent hardware.

## 🚀 How to Use

1. Download or clone this repo.
2. Open `index.html` in any modern browser.
3. Type how many apples you want.
4. Press **Spawn** (or hit Enter).
5. Stare. Get smarter.

```bash
git clone https://github.com/last1chan/Apple-Spinning-Theory.git
cd Apple-Spinning-Theory
# just open index.html in your browser, no install needed
```

> The page loads Three.js from a CDN, so you need internet the first time.
